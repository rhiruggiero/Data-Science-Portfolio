**TSA Complaints Visual Analysis**

A visual project that uses a database of TSA complaint data at various airports.

**Introduction**

In this project, I aim to reveal where more training may be needed for TSA staff and other suggestions to improve customer experiences in a theoretical scenario.

**Data**

The data used for this project can be found in the repository.

**Tools used for this project:**

-	Tableau

**Modeling methods:**

This project does not include any modeling, however it includes a visual analysis of data using Tableau.
