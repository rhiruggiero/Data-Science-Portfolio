**Fantasy Football Analysis**

A project completed in one of my courses to analyze fantasy football data.

**Introduction**

This project aims to draw conclusions from a fantasy football data set using Python and statistical concepts. I use hypothesis testing, create histograms, perform a permutation test and more in this project.

**Data**

The data set for this project can be found in this repository named: FantasyFootballWeekly16.xlsx and also at this link: https://www.kaggle.com/datasets/fishhead/fantasy-football?resource=download

**Tools used for this project:**

-	Jupyter Notebooks
-	Python

**Modeling methods:**

This project explores linear regression modeling.
