**Childcare Cost Visual Analysis**

A visual project that uses a database of childcare costs across the US.

**Introduction**

In this project, I aim to convince others to help with childcare costs to help save money in a theoretical scenario. Tableau was the main source used to complete the visuals in the project.

**Data**

The data used for this project can be found at this link: https://www.dol.gov/agencies/wb/topics/featured-childcare

**Tools used for this project:**

-	Tableau

**Modeling methods:**

This project does not include any modeling, however it includes a visual analysis of data using Tableau.
