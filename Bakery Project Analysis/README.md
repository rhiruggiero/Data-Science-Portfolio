**Bakery Data Analysis**

An exploratory data project using sales data from a bakery.

**Introduction**

This project aims to predict sales for the bakery's top 5 items.

**Data**

The data used for this project can be found at this link: https://www.kaggle.com/datasets/akashdeepkuila/bakery?select=bakery_sales_revised.csv

**Tools used for this project:**

-	Python
- Jupyter Notebook

**Modeling methods:**

This project explores linear regression and random forest modeling.
