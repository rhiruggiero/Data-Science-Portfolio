**Lottery Numbers Visual Analysis**

A visual project that uses three datasets based on different NY lotteries including mega millions, powerball and pick 10.

**Introduction**

In this project, I aim to convince coworkers to join me in buying lottery tickets together to improve our chances of a payout in a theoretical situation. 

**Data**

The data used for this project can be found in the repository and linked here: https://www.kaggle.com/datasets/new-york-state/nys-lottery-information-and-data?select=lottery-pick-10-winning-numbers-beginning-1987.csv

**Tools used for this project:**

-	Tableau

**Modeling methods:**

This project does not include any modeling, however it includes a visual analysis of data using Tableau.
